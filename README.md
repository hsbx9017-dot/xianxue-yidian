# 先学一点

帮助大学生把学习愿望变成可以开始的每日动作，按记录协商调整后续安排。

## 安卓 App 1.1.1

安装包入口：https://hsbx9017-dot.github.io/xianxue-yidian/downloads/xianxue-yidian-1.1.1.apk 。支持 Android 7及以上；需要可正常运行现代网页界面的 Android System WebView。安装后有独立图标与窗口，页面资源随安装包提供，查看计划、规则生成、执行步骤、每日反馈和学习档案不依赖网页在线；DeepSeek生成、在线课程和提交建议仍需网络。

### 1.1.1：手机软件与通知修复

- 顶部“免费软件”和计划材料上方增加 AnkiDroid、GeoGebra 计算器套件、Termux + Python。每个入口有免费范围、官方来源、首次操作、离线条件和可留下的结果，不要求全装。安卓可打开已安装的对应软件；未安装会明确报错。
- Python运行方式新增“安卓手机”，保存和备份保留选择；使用Termux时给出首次安装Python与后续运行步骤，不推荐安卓安装桌面Thonny。
- 修复固定版本 Capacitor Local Notifications 8.3.1 重复通知后续调度丢失RTC_WAKEUP与allowWhileIdle的问题。构建前应用版本锁定、幂等的窄补丁；依赖改变时要求重新核对。Android JVM回归测试直接执行通知接收器，检查四种模式下一次闹钟均会唤醒CPU。该测试不能代表MIUI真机隔夜测试。
- 应用启动或返回前台时，在已开启提醒、通知权限允许的前提下重排下一次提醒；不代替用户打开权限。
- 新增通知分类、闹钟权限、省电状态、自启动的诊断和设置入口。MIUI自启动不能可靠读取，因此不显示虚构的“已开启”。
- 系统发布与用户确认收到分别记录，仅保存在本机。排程登记和系统notify调用均不能保证人看见通知；旧版本没有诊断时不补造历史。
- 可打开系统时钟，带入时间和每天重复参数；保留系统界面供用户核对、保存。不能读取时钟是否真正保存成功，也不能在关闭普通通知时自动取消时钟里的独立闹钟。
- 升级保留com.xianxue.yidian与原签名，versionCode为111；直接覆盖安装，更新前可备份，不要先卸载。

软件来源核对日期2026-10-27：Anki官方 https://apps.ankiweb.net/ 、GeoGebra官方 https://www.geogebra.org/download 、Termux官方 https://termux.dev/en/ 。APK从开发者或其认可的F-Droid入口获取，不复制分发第三方安装包，不提供付费会员功能。

### 手机上怎么开始

1. 下载并按手机提示安装“先学一点”，然后在桌面点图标打开。
2. 如有旧记录：先在原来用过的网页中导出JSON备份，再在App的“学习档案”中导入。网页与App数据分开，当前没有账号云同步。
3. 展开“安卓App · 每日提醒”，选择08:00或自己的时间，点击开启；只有用户点击时才申请通知权限。
4. 点击“30秒后测试通知”，回桌面等候并从通知返回，确认红米系统没有拦截。需要更准时时手动允许“闹钟与提醒”，再保存/修复日程。红米的自启动、后台运行和省电设置可能影响通知；强行停止、关机、通知权限关闭时不能保证送达。
5. 每天点“两分钟启动”，按准备、动手、检查逐步勾选。结束后记录真实完成情况，获取肯定、卡点观察和下一学习日建议；只有点“采用”才改后续任务，休息日、已完成日和已手改的安排不会被静默覆盖。

每日反馈不调用模型，不产生API费用；它基于自述记录，不代表掌握程度测评。实际用时可以留空，不自动用计划时长冒充。每日记录、步骤进度、反馈与已采用的调整进入JSON备份；协商重排同一周时保留已经记录的日期。当前日期之后不能提前打卡。

### 安卓开发

前端与网页共用React/TypeScript代码，使用官方Capacitor封装；定时通知由Android本地日程安排，无需浏览器后台、FCM或新增推送服务账号。未在普通网页中冒充“关闭页面也会提醒”。

`npm run android:sync` 构建前端并同步到 `android/`。原生项目使用Java21、Android SDK36；`bash android/gradlew` 应在android目录调用。GitHub工作流 `android.yml` 在mobile分支更新或手动启动时运行测试、构建并校验签名，产物为release APK。签名材料仅在被忽略的本机目录与仓库Actions secrets中保留，公开仓库只保存证书指纹，不保存私钥。更新版本必须沿用签名与提高versionCode。

安卓不自动备份到系统云端；卸载前应通过“学习档案”导出JSON，在系统分享窗口选择保存文件或分享给自己。关闭提醒会取消本应用的每日与测试通知，不删除学习记录。

学习工具部署于 GitHub Pages。反馈使用独立的 Supabase 数据库；本地管理员服务只绑定 127.0.0.1。

## 体验

- 明确目标 / 寻找方向两个入口。
- 四步引导、七天计划、每日时间上限、留白日。
- 高数记录教材名称、版次、册别与学习范围；教材不明时先确认，未知页码、题号不编造。规则版含极限、导数、一元积分的独立例题与检查点，自填章节以本校材料为准。
- 英语可选阅读、听力或跟读，给出 LearnEnglish、词典入口与具体用法；已有教材优先。
- Python 是独立方向，配中文入门课程、Thonny 或浏览器运行工具、短代码、预期输出和5分钟轻量路线。
- 生成结果包含材料清单、准备步骤、每日“准备—动手—检查”、本周成果标准；下载的 Markdown 一并保留。
- 规则体验版不需要密钥，明确标为非 AI 生成。
- DeepSeek AI：每位访客填写自己的 API 密钥，浏览器直接请求 `https://api.deepseek.com/chat/completions`。
- 解释计划依据与取舍，支持协商修改、单日编辑、完成记录及Markdown下载。
- 朋友免登录点击提交反馈，收到数据库保存回执后才显示成功；失败时保留当前输入，重试相同内容不会重复保存。
- 本地管理支持浏览全部反馈、分页、标记已处理、只看未处理和 Markdown 导出。
- 学习选择自动保存为草稿；支持多个目标、1至52周路线、截止日期、每周复盘、接续下一周和历史完成记录。
- “学习档案”可导出和导入JSON备份。旧版最近一周的记录自动迁移；未生成计划的选择也会保存。

## 密钥和数据

密钥只在当前页面内存保留，刷新后清除。不存储于localStorage、Cookie、代码或仓库，不经过本站服务器，也不使用创建者额度。学习计划可保存在本机浏览器；反馈与导出不含密钥。

API费用由填写密钥的访客自行承担。用户勾选同意后，浏览器仅将密钥发送给DeepSeek。由于是静态站点，无法提供服务端全局限流；页面加载不调用模型，只有明确生成或协商修改才调用。

本仓库不包含个人访谈、聊天记录、DeepSeek 密钥或管理员密钥。`lib/feedback-config.ts` 仅包含反馈服务地址和可公开的提交凭据；它不能读取反馈。

## 长期使用与备份

先设目标周期或截止日期。路线展示每周阶段方向，最近一周生成具体任务；之后点“复盘并安排下一周”，填写已学会的内容、卡点和下周重点，调整时间、材料与范围后继续。不会自动累积未完成任务或假设用户已经掌握。规则版延续练习流程；针对新知识点生成具体题目需使用访客自己的DeepSeek密钥或手动编辑。

草稿、教材、课程、目标、每周计划、复盘和完成标记保存在当前浏览器的 `xianxue-workspace-v2`。存在旧版 `xianxue-v1` 时自动迁移一份周记录，原数据不会因读取失败自动覆盖。保存失败时页面提示，用户仍可导出当前内存中的记录。

“导出全部记录（可恢复）”会生成JSON备份，“导入备份”可恢复；相同目标替换前要求用户确认，其他目标保留。Markdown用于阅读，不能替代可恢复的JSON备份。清除浏览器数据、无痕模式退出、换设备或更换域名会影响本机记录；当前不提供账号和跨设备云同步。学习档案不上传到反馈数据库，API密钥不进入档案或备份。

每目标最多保存200个周记录、最多50个目标，实际可用容量还受浏览器本地存储限制。备份仅接受本站格式、限定字段和已核对资源域名；错误备份不会覆盖现有记录。

## 查看反馈

在配置好的本机双击 `打开反馈管理.cmd`，打开 `http://127.0.0.1:4318/__admin`。从此本地服务打开学习工具，会显示“管理反馈”入口；公开站点没有此入口。仅用 Vite 启动或另存 HTML 不会获得管理员权限。

管理员服务从被 Git 忽略的 `feedback-admin.local.json` 读取 `{ "url": "https://项目.supabase.co", "secretKey": "本地管理员密钥" }`，密钥仅在 Node 服务中使用，不发往浏览器。不要分享此配置文件；换电脑需要另行配置。

反馈只上传评价、问题、建议、体验模式及随机提交编号。数据库自动记录接收时间和处理状态，不附带学习计划、个人描述或模型密钥。反馈表在不公开的 `feedback_private` schema 中，公开 RPC 仅能提交；读取和标记 RPC 只授予 `service_role`。本地管理还验证访问地址、浏览器来源和会话 Cookie，防止其他网页读取本机反馈。

数据库定义：`feedback-service/schema.sql`。Supabase Free 项目可能在一周无活动后暂停；服务暂停时页面会报告提交失败，不会假装保存。可在 Supabase 控制台恢复，参考官方免费方案说明：https://supabase.com/pricing 。匿名入口没有验证码或身份识别，适用于初期小范围试用；大范围公开前应补充防滥用措施。

## 开发与部署

Node.js 24：

```sh
npm ci
npm run dev
npm test
npm run build
npm run pages:prepare
```

完成测试与构建后运行 `node scripts/prepare-pages.mjs`，将静态产物和源码指纹保存到 `docs/`，并一同提交。GitHub仓库的 Settings → Pages → Build and deployment 选择 GitHub Actions。推送至main后，工作流会校验源码与产物的一致性并部署 `docs/`，发布阶段无需重新安装npm依赖。

`base: './'` 适配项目仓库的子路径。页面不依赖路由重写或原Sites域名。

AI接口默认使用官方文档中列出的 `deepseek-flash`。已用模拟响应测试输出校验和密钥边界；真实账户调用效果须以用户实际体验为准。参考：https://api-docs.deepseek.com/ 。

## 学习资源的边界

学习链接来自预先核对的课程与工具官网，最近核对日期为2026-10-22。公开目录可能改变，网站不提供实时检索；MOOC的开课、登录和付费条件以课程页面为准，不将购买或证书作为学习前提。英语A1/A2为可调整的试学起点，不是能力测评。Python官方教程作为查阅资料，中文零基础主课使用北京理工大学《Python语言程序设计》。用户已选其他课程时优先沿用，不将站点推荐冒充为用户选择。

AI沿用程序提供的材料清单，拒绝模型生成的URL。AI仍可能对学习内容判断不准，因此保留手动修改；真实模型效果需在访客自行填写密钥后体验。新增材料字段不会上传到反馈服务。

反馈测试：`npm test` 包含提交数据边界、错误回执、本地管理会话和跨站访问检查。数据库权限测试可在隔离运行库安装后执行：`npm install --prefix outputs/feedback-tests --ignore-scripts @electric-sql/pglite`，再运行 `npm run test:feedback-db`。云端联调脚本 `scripts/check-feedback-live.mjs` 会写入明确标记的测试反馈并标记已处理，需本地项目凭据，不能在公开 CI 中运行。
